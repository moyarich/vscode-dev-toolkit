# VS Code Dev Toolkit

Reusable Node.js tooling for developing, packaging, demonstrating and publishing VS Code extensions.

## Capabilities

- Launch isolated VS Code extension-development workspaces.
- Drive demos and recordings using Playwright and Electron.
- Capture images and video, annotate with caption and magnifier overlays, and produce GIFs.
- Build VSIX archives and publish existing VSIX files to Open VSX.

## Package

Import from `@moyarich/vscode-dev-toolkit`, `@moyarich/vscode-dev-toolkit/demo` or `@moyarich/vscode-dev-toolkit/extension`.

See the package README for the API, and the Development guide for repository setup.
